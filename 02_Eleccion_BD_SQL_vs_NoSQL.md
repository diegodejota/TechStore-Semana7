### Elección de base de datos para TechStore

Para TechStore se eligió una base de datos SQL, esto porque la información que se va a manejar está bien estructurada y tiene relaciones claras entre usuarios, productos, inventario y transacciones.
Esta opción permite mantener mejor la integridad de los datos y controlar de forma más segura las compras y los registros.

Además, SQL facilita el uso de claves, restricciones y relaciones entre tablas, esto es importante para una tienda online, en la cual la información debe estar ordenada y ser confiable.
